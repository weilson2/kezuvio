## Features implemented

The independent `/demo/interior-3d` product reuses the shared visitor session, PostgreSQL workspace repository, simulated roles, generation reset and idempotency boundary. Customer and Manager can edit their visitor workspace; Viewer reads saved designs. Manager alone updates illustrative catalogue prices. These controls are demonstration capabilities, not production authentication.

The domain provides three dimensioned room presets, editable room dimensions and wall/floor surfaces, eight fictional furniture models, insertion/removal and validated whole-centimetre position/size/quarter-turn rotation/finish changes. Axis-aligned floor footprints must fit within the room height/boundaries without overlap; touching edges are allowed. Rejected transforms and room shrink requests retain the saved design. All accepted changes persist immediately; explicit save names/marks the design, load switches selected layout, and duplicate creates independent room and item IDs. At least one design remains after removal. The workspace is bounded to ten designs and thirty items per design.

The verified UI/scene supplies original primitive furniture geometry, selectable scene items, camera orbit/zoom controls, numeric keyboard-accessible transforms, immediate draft material/placement feedback, a priced item list and PNG screenshot export. The scene is lazily loaded; browser checks exercised actual WebGL rendering/camera pixel changes/download signature and a forced unsupported-WebGL fallback that retained numeric editing.

Pricing uses integer sen. Per-item price derives from current catalogue base price, configured footprint relative to the original footprint and the selected finish premium, rounded half up once. Floor and four gross wall areas use explicit illustrative area rates. Repeated instances contribute repeated item quantities. Existing saved designs use current demo rates; they are not frozen commercial quotations. No real supplier price or quotation is implied.

## Limits, costs and next work

This is a fictional room configurator with rectangular axis-aligned floor collision checks and whole-centimetre numeric editing. Quarter-turn rotation is intentional; arbitrary-angle geometry, physical simulation, vertical stacking, structural measurements, real CAD/BIM precision and supplier integrations are excluded. Surface costs use gross wall/floor areas without window/door deductions. Furniture finishes and surface colours are illustrative. Current demo prices recalculate saved layouts.

All changes autosave to the bounded server document; there is no independent unsaved multi-user draft or production account model. Existing one-hour visitor expiry and product reset limits apply. Screenshot export depends on available browser WebGL/canvas capability. No broad mobile-device performance claim is justified before measurement.
