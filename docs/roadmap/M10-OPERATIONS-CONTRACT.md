# Local operations contract

This is one authenticated, loopback-only studio workspace. Demo roles never authorize operations. It records role assignments and human handoffs; executing a task runs only a named local validation check, not an AI model, arbitrary prompt, deployment or message. Codex roles remain available separately through project configuration. No API tokens or billing claims are invented.

`GET /api/operations` returns 401 without an authenticated HttpOnly session. On success returns `{csrf, roles, checks, tasks, metrics, mode}`. Roles have `id,name,responsibility`; checks have `id,label`. Tasks have `id,title,role,check,status,attempts,timeoutSeconds,createdAt,updatedAt,logs[]`, log `{at,event,detail}`. Status is awaiting_approval, approved, running, succeeded, failed, timed_out, interrupted. Metrics have `tasks,attempts,elapsedMs,aiTokens:null,additionalPaidCostSen:0`. Mode explicitly describes loopback/local checks and no live AI dispatch.

POST same endpoint JSON actions: `login` with `key`; `logout`; `create` with `title,role,check,timeoutSeconds`; `approve` with `id`; `run` with `id`; `retry` with `id`; `mock` with `event:'status'|'create'` (mock create creates a fixed Ada/brand task requiring approval). Every action except login requires `X-Operations-CSRF`; all POSTs require exact loopback Origin. Login returns only `{ok:true}` and sets session cookie. Other actions return updated GET shape, except logout `{ok:true}`. Run waits for bounded execution. Retry returns failed/timed_out/interrupted task to awaiting_approval, maximum three attempts. All errors `{error}` with appropriate HTTP status. Inputs reject unknown fields and client workspace identity. Mock events use this same authenticated endpoint and never send messages.

Setup: `npm run operations:setup` creates ignored `.local/operations/config.json` only if absent. Access key stays in that private file. File-backed task state uses atomic replacement and serialized writes, fixed server-derived workspace and bounded history. On restart an unfinished run becomes interrupted. Only one check runs at a time. Session logout is revoked server-side. Maximum 100 tasks, 30 log entries per task, 4KB response output. Quota and actual AI token use remain unavailable; no paid API is enabled.

UI owner: operations route, component/CSS and browser spec only. Backend/domain/config owner: root. Use the shared UI and metadata helper. Show authentication, roles, assignment, approval/run/retry, bounded logs, timeout, usage and mock-event controls. Explain that human approval here authorizes only a local check. Test credentials are ephemeral preview-only and separate from the development key.
