Existing shared session, role projections, origin/CSRF checks, locked workspace transactions, generation resets, bounded audit and durable idempotency are reused.

This batch closes the new roadmap's missing listing restoration requirement. Manager-only `listing.restore` takes the record ID/current version, accepts only Archived listings and restores to **Unavailable**. A manager reviews/edits the listing to Available explicitly. Historical lead/viewing links remain; one retry produces one version/history/audit effect, even from separate connections. Other roles cannot restore, and foreign IDs/stale versions/generations are rejected. No schema change is needed.

Agent workload now includes active agents only; inactive roster records remain available in agent management. Activity shows the affected record's label and stable identifier so assignments are identifiable. Form save/cancel returns keyboard focus to its opener after the pending state clears and avoids overriding focus moved to another view.

## 7. Remaining limitations and security findings

This remains a local fictional demo: one-hour visitor sessions, bounded records/action count, selectable simulated roles, seeded three-agent roster, internal reminders, no external calendar/listing feed/customer communications, no real payments or financial/regulatory compliance claim. Existing legacy QR URL redirects to Cafe; other legacy routes remain intact. Production authentication is not supplied by selecting Manager.

The installed **Next.js 16.4.3** is flagged by npm and its build-time advisory checker. npm reports moderate cache-disclosure/poisoning, image SVG rejection, Edge cookie exposure and response-forwarding advisories affecting ranges through 16.4.4. Sources include [Vercel/Next advisory GHSA-mfr8-8qww-v76h](https://github.com/advisories/GHSA-mfr8-8qww-v76h), [GHSA-7qx7-33qx-rqx2](https://github.com/advisories/GHSA-7qx7-33qx-rqx2) and [GHSA-f3mh-rxg3-f5g2](https://github.com/advisories/GHSA-f3mh-rxg3-f5g2). These are observed advisory matches, not an exploitability determination for this application. Recommend a separately verified compatible security update before any public launch; no dependency upgrade was silently included in this M5 correction.

npm also reports [Effect TemplateLiteral regular-expression denial of service](https://github.com/advisories/GHSA-7589-6fvf-x4pw), propagated through `@prisma/config` and `prisma` (three high entries describing one transitive chain). npm's suggested automatic fix changes Prisma major version; it was not applied blindly. Assess an upstream compatible resolution and actual tooling exposure before release. Passing functional tests does not resolve these findings or establish production security readiness. Track remediation in the master backlog, separately from milestone acceptance.
