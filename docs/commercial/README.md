# Kezuvio commercial draft pack

Prepared23 November2026 for founder review. All figures and terms remain drafts; nothing here is an issued quotation or authorization to send, publish, purchase or deploy.

Start with [service packages](SERVICE-PACKAGES.md) and the [editable estimate workbook](../../outputs/roadmap-m12/kezuvio-estimates.xlsx). Read the [model guide](ESTIMATE-MODEL.md) for sen inputs, effort/cost/margin calculations and sample assumptions. The workbook's example selling prices are not the approved website price list.

Use the templates in engagement order. Copy each file for the client/project, fill its deliberate fields, retain revision IDs, and obtain the relevant scope/commercial/legal/tax approvals before external use.

| Document                                                           | Purpose                                                                                      |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| [Client questionnaire](client-templates/CLIENT-QUESTIONNAIRE.md)   | Capture objectives, users, workflows, data, integrations, constraints and decisions          |
| [Project proposal](client-templates/PROJECT-PROPOSAL.md)           | Present the scoped approach, outcomes, dependencies and delivery assumptions                 |
| [Quotation](client-templates/QUOTATION.md)                         | Record line items, exclusions, optional/recurring costs and pending commercial/tax decisions |
| [Scope of work](client-templates/SCOPE-OF-WORK.md)                 | Define deliverables, acceptance, responsibilities, revisions and change boundaries           |
| [Change request](client-templates/CHANGE-REQUEST.md)               | Evaluate and authorize a specific scope/cost/schedule change                                 |
| [Acceptance checklist](client-templates/ACCEPTANCE-CHECKLIST.md)   | Record evidence, exceptions, defects and an explicit acceptance decision                     |
| [Maintenance agreement](client-templates/MAINTENANCE-AGREEMENT.md) | Agree support scope, hours, responsibilities, recurring charges and exclusions               |
| [Handover](client-templates/HANDOVER.md)                           | Transfer verified artifacts, ownership, access process, runbooks and open responsibilities   |

The editable source format is Markdown, matching the repository's documentation. Use a Markdown editor or copy the drafts into your chosen document system. Fillable template fields are intentional. No real client data belongs in public demos or this shared pack, and secrets belong in approved private channels rather than handover text.

[Sales materials](SALES-MATERIALS.md) contains factual portfolio copy, walkthrough scripts, comparisons, website copy, social drafts and FAQ. [Business readiness](READINESS.md) identifies what is available locally and what remains before a public launch or paid customer engagement. Current technical evidence is in [M11](../roadmap/M11-REPORT.md); [M12's handoff](../roadmap/M12-REPORT.md) records delivery/verification limits. All milestone acceptance remains with the founder.
